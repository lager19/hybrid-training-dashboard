🏃‍♂️ Hybrid Training Dashboard — Setup

Verbinde dein Strava-Konto und konfiguriere deine Ziele · ca. 15–25 Min

👋 Willkommen

Dieses Dashboard zieht deine Strava-Aktivitäten live, berechnet HF-Zonen aus deiner Schwelle und zeigt deinen Trainingsfortschritt Richtung Zielwettkampf.

Was du brauchst:

  1. Strava-Account mit API-App (kostenlos, gleich erklärt)
  2. Cloudflare-Account (kostenlos, kein Kreditkarte nötig)
  3. 10–25 Min Zeit für Setup
💡 Warum Cloudflare? Strava verlangt einen geheimen Schlüssel ("Client Secret"), der nicht im Browser stehen darf. Ein winziger Cloudflare-Worker (kostenlos, 0€) hält den Schlüssel sicher und liefert deine Daten ans Dashboard. Setup dauert ~10 Min.
⚠️ Wenn du schon ein eigenes Backend hast (z.B. weil jemand das für dich eingerichtet hat) oder den OAuth-Flow lieber überspringst: klick unten auf "Schon eingerichtet".

🏋️ Welche Sportarten?

Wähle die Sportarten, die du regelmäßig trainierst. Nur diese werden im Dashboard angezeigt — Tabs, Charts und Plan-Einheiten passen sich an deine Auswahl an.

Du kannst das später jederzeit über das ⚙️-Settings-Menü ändern.

💡 Wenn du dir unsicher bist: wähle das, was du in den letzten 4 Wochen am häufigsten gemacht hast.

2Strava-API-App anlegen

Auf strava.com/settings/api öffnen und falls noch keine App vorhanden, eine neue anlegen:

  1. Application Name: Mein Training Dashboard (frei wählbar)
  2. Category: Training
  3. Website: http://localhost
  4. Authorization Callback Domain: localhost (wichtig!)
  5. Klick "Create"

Du landest auf der App-Detail-Seite mit den Credentials. Trage sie hier ein:

🔒 Der Client Secret bleibt in deinem Browser bzw. wandert gleich in deinen eigenen Cloudflare-Worker — er wird nirgendwo sonst hingeschickt. Behandle ihn wie ein Passwort.

3Cloudflare-Worker deployen

A. Cloudflare-Account anlegen (falls noch nicht):

  1. Gehe zu dash.cloudflare.com/sign-up
  2. Email + Passwort, keine Kreditkarte nötig

B. Worker erstellen:

  1. Linke Sidebar: Workers & Pages → Create application → Create Worker
  2. Name: strava-proxy (frei wählbar — merke dir den Namen)
  3. Klick Deploy (deployed den Default-Worker — gleich ersetzen)
  4. Auf der Worker-Seite oben rechts: Edit Code
  5. Im linken Editor: gesamten Default-Code löschen und unten stehenden Worker-Code einfügen, dann oben rechts Save and Deploy
